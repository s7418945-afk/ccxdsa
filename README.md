# ccxdsa

## Интроспекция цветовой гаммы

Запустите автономный пример командой:

```bash
./palette_inspection.py
```

Скрипт задаёт палитру `Океан` и простыми словами объясняет её основные атрибуты
(`name`, `colors`, `size`, `hex_colors`) и методы (`color_at`, `__iter__`).
Модуль `inspect` используется, чтобы показать сигнатуры методов и найти
встроенные типы исключений Python. Для запуска нужен Python 3.
